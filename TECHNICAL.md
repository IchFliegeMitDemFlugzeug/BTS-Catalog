# Техническое описание BTS-Catalog

## 1. Назначение

Книга предназначена для регистрации собственных деталей, сборочных единиц и стандартных изделий, отображения их состава и формирования заказов. Повторное применение одной детали в различных сборках не создаёт дублирующихся записей.

**Девять пользовательских листов:** Новое изделие, Перечень деталей, Штуцеры, Крышки, ДУТ, ДТ, Стандартные изделия, Заказ, Справка.

**Служебный лист:** _BTS_DATA, создаётся автоматически и скрыт (VeryHidden). Это хранилище связей и заказа, а не пользовательский перечень.

assets/BTS.xlsx — оформленная исходная книга. BTS.xlsm — рабочая книга с VBA. Скрипт scripts/build.py встраивает VBA из src/BTS.bas, src/Localization.bas и src/ThisWorkbook.cls, сохраняя девять исходных листов.

## 2. Структура обозначения

**Деталь:** BTS.XX.MM.DDAA.NNN. **Сборка:** BTS.XX.MMMM.DDAA.NNN.

| Поле | Назначение |
|---|---|
| BTS | Префикс |
| XX | SH — штуцеры; KR — крышки; DU — ДУТ; DT — ДТ |
| MM | Двухсимвольный код группы материала детали |
| MMMM | Первые два символа — материал основания, вторые два — материал головки сборки |
| DD | Диаметр трубки в десятых долях миллиметра: 45 = 4,5 мм |
| AA | Угол в градусах: 00 — прямой, 30, 45, 60, 90 — угловой |
| NNN | Регистрационный номер: последняя цифра 0 — сборка; другие цифры — деталь |

Исходные коды: AL — алюминиевый сплав, BR — бронза, LA — латунь, ST — коррозионностойкая сталь. Исходные марки: Д16Т, БрАЖ9-4, ЛС59-1, 12Х18Н10Т.

BTS.SH.BRAL.4590.000 означает штуцер под трубку Ø4,5 мм и углом 90° с бронзовым основанием и алюминиевой головкой.

Функция AutomaticName автоматически предлагает название готового штуцера, например «Штуцер угловой 90°, под трубку Ø4,5 мм». Поле наименования можно заменить вручную, что необходимо для основания, головки и других отдельных компонентов.

## 3. Источники данных

| Лист или диапазон | Данные |
|---|---|
| Перечень деталей, A:C | A: обозначение; B: наименование; C: марка материала |
| Стандартные изделия, A:B | A: обозначение; B: наименование |
| _BTS_DATA, A:E | A: обозначение сборки; B: наименование; C: группа; D: адрес гиперссылки; E: внутренний адрес |
| _BTS_DATA, F:I | F: родитель; G: компонент; H: количество; I: роль компонента |
| _BTS_DATA, K:L | K: корневая позиция заказа; L: количество |
| _BTS_DATA, N:O | N: корень заказа; O: исключённый путь в дереве |
| _BTS_DATA, U, Z, AA:AF | Вспомогательные списки выбора |

Номенклатура деталей имеет одну запись на обозначение. В деревьях отображаются её наименование, материал и гиперссылка, полученные из первичного перечня.

## 4. Деревья сборок

Листы Штуцеры, Крышки, ДУТ и ДТ показывают зарегистрированные сборочные единицы соответствующего семейства. Каждый следующий уровень вложенности расположен в отдельном столбце: уровни 1–6 в A:F; G — наименование, H — материал, I — количество.

Excel группирует строки дочерних компонентов для раскрытия кнопкой «+». Столбцы J:K скрыты и содержат служебные идентификаторы родителя и пути.

Корневые сборки сортируются целыми блоками по диаметру и углу, затем по материалу и номеру. В составе сборки сначала следуют подсборки, затем собственные детали, затем стандартные изделия; внутри групп — по обозначению.

Текущая реализация поддерживает отображение до шести уровней вложенности. Превышение этого предела вызывает сообщение об ошибке.

## 5. Новое изделие

В ячейке B1 выбирается вид изделия: «Деталь» или «Сборочная единица». Группы обозначения расположены в A4:F4, полное обозначение показывается в G4. Наименование находится в объединённой области B6:G6.

Для детали виден один код материала, а также поле марки материала B7:D7. Список марки фильтруется по коду материала и данным справки. Поле второго материала и таблица состава скрыты. Последняя цифра номера должна быть от 1 до 9.

Для сборочной единицы доступны два кода материала, поле марки сплава скрыто. Состав вводится в A11:D50 (обозначение, наименование, количество, роль). Последняя цифра номера должна быть 0. Для штуцера наименование формируется автоматически. Материалы основания и головки проверяются на соответствие обозначению выбранных компонентов.

Суффикс вводится в текстовую ячейку F4, дополняется ведущими нулями до трёх знаков и проверяется на соответствие выбранному виду изделия. При смене вида незавершённый состав и марка материала очищаются. Начальный номер равен 001 для детали и 000 для сборки.

На форме только кнопка «Добавить изделие». При сохранении проверяются уникальность обозначения, наличие марки материала детали или корректность состава сборочной единицы.

## 6. Удаление

На листе Перечень деталей удаляется первичная запись, с предупреждением о прямой и косвенной применяемости в сборках. Удаление подтверждённой детали исключает её из всех составов.

На листах Штуцеры, Крышки, ДУТ и ДТ удаление дочерней позиции удаляет только связь с выбранной сборкой, а удаление корневой сборки — саму сборочную единицу.

На листе Заказ удаление исключает выбранную ветвь только из текущего заказа. Исходный конструкторский состав не изменяется.

## 7. Заказ и экспорт

На листе Заказ обозначение собирается по составным полям A2:F2. G2 — полное обозначение, H2 — количество. Допускаются только зарегистрированные номера. Дерево начинается с восьмой строки, глубина отображается через соседние столбцы. В L каждой строки размещено действие «Удалить выбранное»: двойной щелчок исключает соответствующую ветвь из заказа.

Алгоритм CountLeaves рекурсивно раскрывает сборки. Количество каждого конечного компонента равно произведению количеств вдоль пути и количества корневого изделия. Исключённые ветви не учитываются. Одинаковые детали и стандартные изделия суммируются по полному обозначению. При обнаружении сборки без компонентов расчёт прерывается с ошибкой, чтобы не пропустить потребность.

Процедура BTS_ExportOrder создаёт рядом с основной книгой файл BTS_Order_YYYYMMDD_HHMMSS.xlsx. В нём два раздела: детали собственной разработки и стандартные изделия; позиции упорядочиваются по полному обозначению.

Результат является **сводной ведомостью потребности**, а не оформленной спецификацией ЕСКД. Алгоритм не следует представлять как полную реализацию сортировки ГОСТ Р 2.106-2019.

## 8. Справка

Поля текущего макроса:
- A2:A5: группы изделий;
- A9:A15: коды материалов;
- A17:C26: марки с кодами материалов;
- A28:A36: допустимые диаметры;
- A38:A46: углы.

Допускается заполнять свободные строки в перечисленных диапазонах. Если список вырастет за них, нужно расширить соответствующий именованный диапазон в BTS_ReferenceInit.

Гиперссылку на чертёж вводят прямо в ячейку обозначения детали или сборочной единицы. При перестройке дерева ссылки копируются из первоисточника.

## 9. Проверка

GitHub Actions проверяет сборку VBA-проекта, наличие девяти листов, кода макросов и упаковку формата XLSM. Проверка выполнения части VBA ограничена возможностями стороннего интерпретатора, в частности он не реализует Shape.Fill. Полный цикл работы кнопок, редактирования, удаления и экспорта в настоящем Microsoft Excel ещё требует проверки до реального применения.
