# Техническое описание BTS-Catalog

## Назначение
Единая книга для регистрации собственных деталей, сборочных единиц, покупных стандартных изделий и расчёта потребности для заказа. Источники данных и представление в деревьях разделены: повторная запись детали в разных сборках не создаёт новых экземпляров её карточки.

## Листы
1. **Новое изделие**: регистрация и изменение изделий через составные поля обозначения; выбор состава из зарегистрированных изделий.
2. **Перечень деталей**: единственный источник обозначения, наименования и марки материала каждой детали; ссылка на чертёж устанавливается на ячейку обозначения.
3. **Штуцеры**, **Крышки**, **ДУТ**, **ДТ**: представления дерева сборочных единиц. На каждом следующем уровне обозначение помещается в следующий столбец, НЕ в отступ внутри одной ячейки. Корни сортируются целыми блоками.
4. **Стандартные изделия**: пользователь заполняет обозначения и наименования покупных изделий по стандартам.
5. **Заказ**: ввод составного обозначения, количества, дерево предварительного заказа, исключение ветвей только из текущего заказа, экспорт сводной ведомости конечных компонентов.
6. **Справка**: все редактируемые классификаторы и марки материалов.

Скрытая служебная таблица **_База** хранит сборочные единицы, составы, корни заказа и индивидуальные исключения его ветвей. Пользователь работает только на девяти перечисленных листах. Служебные таблицы не являются отдельными пользовательскими каталогами.

## Обозначение
Общий формат **BTS.XX.MM.DDAA.NNN**.
- BTS: префикс.
- XX: SH (штуцеры), KR (крышки), DU (датчики уровня топлива), DT (датчики температуры).
- MM: для детали 2 символа материала, для сборочного штуцера 4 символа (материал основания + материал головки).
- DD: внутренний диаметр трубки в десятых долях миллиметра для SH, от 00 до 99 (например, 45 означает 4,5 мм).
- AA: угол 00, 30, 45, 60, 90 (для SH); 00 соответствует прямому штуцеру. Специальные псевдоуглы 99 не применяются.
- NNN: три цифры, последняя 0 означает сборочную единицу, остальные значения означают деталь. Уровень вложенности не кодируется.
Коды материалов AL (алюминиевый сплав), BR (бронза), LA (латунь), ST (коррозионностойкая сталь). Список допускает расширение через «Справку». Начальные марки Д16Т, БрАЖ9-4, ЛС59-1, 12Х18Н10Т.

Автоматическое наименование применимо только к готовому штуцеру: «Штуцер прямой, под трубку Ø4,5 мм» или «Штуцер угловой 90°, под трубку Ø4,5 мм». Наименования отдельных деталей и других семейств назначает конструктор.

## Инварианты
- Собственная деталь определяется одной строкой листа «Перечень деталей».
- Собственная сборка определяется одной строкой технического реестра; её состав — связями (родитель; компонент; количество; роль).
- Покупное стандартное изделие определяется обозначением из видимого одноимённого листа.
- Компонент может повторно применяться в любом количестве сборок; его наименование, материал и ссылка отображаются из первоисточника.
- Циклическое включение сборок запрещается, количество целое положительное.
- Изменение состава не меняет обозначения прочих изделий.
- При удалении детали из перечня предупреждать о всех непосредственных применениях; при подтверждении удалить запись и её связи во всех составах.
- Удаление на листе семейства относится к выбранной сборке/её связи с компонентом. Удаление на листе заказа действует ТОЛЬКО на заказ.
- Деревья перестраиваются целиком на основании сохранённых связей, корни сортируются как единые блоки. Зафиксированные ссылки переносятся с первоисточников.
- Группировка строк Excel раскрывает и сворачивает потомков; обозначения разных уровней находятся в соседних столбцах.
- Заказ содержит корни и индивидуальные исключения ветвей; удаление ветви заказа не изменяет КД и другие ветви.
- Выходной файл — сводная ведомость потребности в деталях и стандартных изделиях, а НЕ спецификация конкретной сборки по ЕСКД. После раскрытия вложенных сборок позиции суммируются по обозначению.

## Макросы
`BTS_Init`: создать и настроить 9 пользовательских листов и скрытую базу, если их ещё нет.
`BTS_AddItem`: валидировать номер, материал, уникальность, состав; зарегистрировать деталь или сборку.
`BTS_EditItem`: загрузить изделие в форму для изменения и сохранить обновлённый состав.
`BTS_AddComponent`: добавить выбранный зарегистрированный компонент и количество в форму сборки.
`BTS_DeleteSelected`: выполнить удаление в контексте активного листа.
`BTS_RebuildAll`: восстановить деревья из источника данных, с сортировкой корней и компонентов.
`BTS_AddToOrder`: добавить выбранное зарегистрированное изделие и количество к заказу.
`BTS_ClearOrder`: очистить только заказ.
`BTS_ExportOrder`: расчёт с учётом вложенности, исключённых ветвей, суммирование и экспорт нового .xlsx.
`Workbook_Open`: инициализировать книгу при открытии, если первый запуск.

## Порядок расчёта заказа
Для каждой корневой позиции с количеством Q рекурсивно обходятся связи состава. Для каждой связи с количеством q накапливается Q*q. При встрече конечной собственной детали или покупного изделия количество суммируется в словаре по полному обозначению. Запрещённые по заказу пути пропускаются. Конечные позиции делятся на разделы «Детали» и «Стандартные изделия»; затем упорядочиваются по обозначению внутри разделов. Это внутренний порядок реестра, не заявляемый как полная реализация сортировки ЕСКД.

## Ограничения проверки
Проект VBA формируется автоматически. Запуск кнопок и работа с объектной моделью Excel должны проверяться в настольном Microsoft Excel с разрешёнными макросами. Нельзя подменять проверку VBA проверкой внешнего вида файла.
