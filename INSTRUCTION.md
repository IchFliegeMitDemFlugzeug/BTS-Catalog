# Инструкция по работе с BTS-Catalog

## Открытие
Открывайте `BTS.xlsm` в настольном Microsoft Excel. Разрешите макросы для файла из доверенного источника. Если Excel блокирует макросы загруженного из интернета файла, откройте его свойства в Проводнике Windows и снимите блокировку (при необходимости и только после проверки происхождения файла). Сохраняйте основную книгу перед выгрузкой заказа, чтобы выходной файл создавался в той же папке.

## Регистрация изделия
1. На листе **Новое изделие** выберите «Деталь» или «Сборочная единица».
2. Заполните поля обозначения. Для детали выберите один материал и марку, укажите наименование, номер с последней цифрой 1–9. Нажмите «Добавить изделие».
3. Для сборки задайте два кода материалов и номер с последней цифрой 0. Выбирайте компоненты раздельно в строках «Детали и сборки» и «Стандартные изделия». Укажите количество и нажмите соответствующую кнопку «Добавить в сборку».
4. В таблице «Состав» можно изменить количества и роли. Повторное добавление того же обозначения суммирует количество. Кнопка «Удалить» убирает позицию только из черновика. Для штуцера укажите роли «Основание» и «Головка»; остальные компоненты имеют роль «Прочее».
5. Когда состав содержит не менее двух разных зарегистрированных компонентов, нажмите **Добавить изделие**. Сборка попадёт на соответствующий лист группы вместе со всем составом. Недостающие детали сначала зарегистрируйте в режиме детали; смена вида изделия очищает незавершённый черновик.

## Детали и покупные изделия
**Перечень деталей** — единый первичный каталог деталей собственной разработки, в том числе используемых в нескольких сборках. Наименование и марка материала не вводятся повторно в состав каждой сборки.

**Стандартные изделия** — ручной перечень покупных изделий. В обозначении указывайте стандартизованное наименование с типоразмером и необходимым классом/материалом, например `Гайка M5 DIN 439-B A2`. Не приписывайте неустановленные классы прочности. Обозначение должно позволять однозначную закупку.

## Ссылки на КД
Добавляйте гиперссылку непосредственно в ячейку обозначения через Ctrl+K. Источником ссылки для собственной детали является «Перечень деталей». Ссылка сборочной единицы хранится в её записи и переносится при перестроении дерева.

## Удаление
Действие **Удалить выбранное** относится к активному листу:
- на «Перечне деталей» удаляет деталь из всей номенклатуры с предупреждением о применениях;
- на листе семейства удаляет выбранную сборку либо её компонент из состава соответствующего родителя;
- на листе «Заказ» исключает выделенную ветвь из текущего заказа без изменения исходного состава изделия.

## Заказ
1. На листе «Заказ» составьте обозначение по группам через выпадающие списки (к выбору допускается только зарегистрированное изделие).
2. Укажите количество и нажмите **Добавить**.
3. В дереве заказа (начиная с 8-й строки) проверьте состав. Для исключения позиции дважды щёлкните по ячейке «Удалить выбранное» в её строке (столбец M) и подтвердите удаление. Это изменит только текущий заказ, а не состав зарегистрированного изделия.
4. **Очистить заказ** полностью обнуляет текущий заказ и исключения, не изменяя каталог.
5. **Сформировать заказ** создаёт рядом с основной книгой отдельный `.xlsx` со сводным количеством конечных деталей и покупных стандартных изделий. В нём нет промежуточных сборок. Это ведомость потребности, а не спецификация ЕСКД.

## Обозначения
Формат: `BTS.SH.ALAL.4590.000`. Значения: SH — штуцер; ALAL — материалы основания и головки; 45 — Ø4,5 мм; 90 — 90°; 000 — сборочная единица. Для детали код материала занимает два символа, например `BTS.SH.AL.4500.001`. Угол 00 означает прямой штуцер.

## Проверка перед реальной закупкой
Проверяйте состав каждой сборки, количество, наличие покупных изделий в справочнике и правильность выгрузки. Сводная ведомость потребности не заменяет утверждённую конструкторскую документацию.

## Номера и дерево
Первый столбец всех таблиц — порядковый номер, он пересчитывается автоматически. В «Справке» каждый раздел начинается с 1. В деревьях используйте знаки +/− слева для строк и над столбцами для последовательного раскрытия следующих уровней. Номер, корневое обозначение, наименование, материал и количество не скрываются вместе с дочерними столбцами. В заказе поля выбора остаются доступны в любом состоянии дерева. Номера не являются обозначениями изделий.
